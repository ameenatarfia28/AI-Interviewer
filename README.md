# AI Interviewer 🤖

An AI-powered technical interview practice application.

## Phase 1 Features

- Subject selection
- Difficulty selection
- AI-generated interview questions
- Candidate answer submission
- AI-based answer evaluation
- Score generation
- Personalized feedback
- Final interview report

## Tech Stack

- Python
- Streamlit
- Google Gemini API
- Prompt Engineering
- python-dotenv
